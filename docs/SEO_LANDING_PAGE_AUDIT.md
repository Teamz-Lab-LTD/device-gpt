## 2. Screens & Flows

1. **Main (Tabbed) –** Single-activity app; tab bar drives main content.
2. **Device Info tab –** Device information, CPU, RAM, storage, FPS, security status, privacy scanner, mic/camera logs, spyware detection, GPS spoofing.
3. **Network Info tab –** Network type, IP, WiFi signal, speed test, latency, ISP privacy, reachability.
4. **Health tab –** Health score, daily streak, scan device health, insights, suggestions, tasks, temperature history, privacy/threat/safe, RAM, storage, battery, cache, optimizations.
5. **Power tab –** Power consumption, component breakdown, camera power test, display power sweep, CPU microbench, network RSSI sampling, device sleep tracker, app power monitor, CSV export dialogs.
6. **Leaderboard tab –** Global leaderboard by category (Battery Saver, Speed Champion, Photo Saver, Bright Screen, Healthy Phone, Getting Better, Balanced Power, Cool Phone, Smooth Runner, App Power Ranking, Best Device); search; upload data; View Insights / Best Devices sub-screens.
7. **Device Insights screen –** Aggregated device insights (from LeaderboardSection).
8. **Best Devices screen –** Best devices comparison (from LeaderboardSection).
9. **Drawer (navigation drawer) –** Premium card, real-time monitor toggle, app permissions, notifications, widget setup (home/lock), leaderboard account, promotional links, review, Generate Verified Report, Verify a Report, Share with Friends, View Source Code on GitHub.
10. **Certificate flow (modal) –** Can your device get certified? Original price, currency, Generate My Device Certificate.
11. **AI Assistant dialog –** Simple / Advanced modes; share device data to AI apps (ChatGPT, Gemini, Claude, etc.).
12. **Item-specific AI dialog –** AI insights for a single metric (e.g. health item).
13. **Verified Report dialog –** Generate shareable code; “What was recorded (100% full device insight)”; Done.
14. **Verify a Report dialog –** Paste code, Verify; Verified / Not verified / No report found / error.
15. **Viral Share dialog –** Share with friends; referral code; Copy.
16. **Data Retention Reminder dialog –** Keep your data safe; link Gmail; Maybe Later.
17. **Premium / Paywall –** DeviceGPT Premium, remove ads, RevenueCat paywall.
18. **Premium Purchase dialog –** Get Premium; Got it!
19. **Premium Info dialog (drawer) –** Premium Active; ad-free experience; Got it.
20. **Widget instructions dialog –** Add Device Monitor Widget; home screen vs lock screen steps; what widget shows; data updates; tip.
21. **Permission / Usage Stats dialog –** Allow; Cancel (drawer).
22. **Notification dialog –** Notifications enabled/disabled (drawer).
23. **Settings (intent) –** Open device settings, developer options (via intents).
24. **Theme selector –** Light / Dark (QuickThemeSwitcher dropdown).
25. **Lock screen widget –** Home/lock screen widget (Android 13+ lock screen); tap opens app (navigate_to_tab: health, power, device_info, network_info, leaderboard).

### Navigation / deep links

- **Tab names (intent extras):** `navigate_to_tab`: "health", "power", "device_info", "network_info", "leaderboard".
- **Widget:** `source`: "lock_screen_widget"; `widget_action`; `navigate_to_section` (legacy index).
- **Referral deep link:** `debugger://referral`; also Play Store HTTPS link for referrals.

## 3. Features & Capabilities

- **Device information & performance** – CPU, RAM, storage, FPS, device model, Android version, security (root, developer mode); real-time monitoring via ActivityManager, BatteryManager, Choreographer. (device_info_ui.kt, device_utils.kt, SystemMonitorService.kt)
- **Privacy & security scanner** – Mic/camera usage detection, spyware/scree recorder/keylogger detection, GPS spoofing detection, motion-while-locked detection, privacy score. (device_utils.kt, device_info_ui.kt)
- **Network monitoring & ISP privacy** – Network type, IP, WiFi signal, real speed test (e.g. Cloudflare), latency, DNS/SSL/DPI/tracking checks. (network_ui.kt, network_utils.kt)
- **Health scoring & streaks** – Health score (0–10), daily streak, best score, improvement suggestions, achievements. (health_section.kt, health_score_utils.kt, power_achievements.kt)
- **Power consumption analysis** – Real-time power (W), component breakdown (camera, display, CPU, network), camera power test, display power sweep, CPU microbench, network RSSI sampling, app power monitor, CSV export. (power_consumption_card.kt, power_consumption_utils.kt, PowerConsumptionAggregator.kt, power_recommendations.kt, power_alerts.kt, power_education.kt)
- **AI Assistant** – “Ask AI” on metrics; Simple/Detailed prompts; share to ChatGPT, Gemini, Claude, DeepSeek, Perplexity, Copilot, Grok, You.com, Replika. (ai_assistant_dialog.kt, ai_prompt_generator.kt, robust_ai_sharing.kt)
- **Device certificate** – Generate certified phone report with resale value (AI); viral certificate. (MainActivity.kt)
- **Leaderboard** – Global rankings by category; Gmail linking; anonymous auth; Best Device / Device Insights; App Power Ranking; data retention reminder. (LeaderboardSection.kt, LeaderboardManager.kt)
- **Verified report** – Generate and verify signed report (“100% full device insight”). (VerifiedReportDialog.kt, VerifiedReportManager.kt, ReportSigner.kt)
- **Lock screen widget** – Health score, streak, battery, temperature, power, RAM, network on home/lock screen (Android 13+). (LockScreenMonitorWidget.kt)
- **Real-time monitor (foreground service)** – Continuous monitoring; toggle in drawer. (SystemMonitorService.kt)
- **Device sleep tracker** – Sleep/wake patterns for battery. (DeviceSleepTracker.kt)
- **Referral system** – Share and track referrals; ViralShareDialog, referral_manager.kt.
- **In-app review** – Google Play In-App Review. (ReviewPromptManager.kt)
- **Feature flags (RemoteConfig):** show_interstitial_ads, show_banner_ads, show_app_open_ads, show_native_ads, show_rewarded_ads, interstitial_ad_interval, enable_leaderboard, leaderboard_tab_position, leaderboard_ad_frequency, show_leaderboard_interstitial_ads, leaderboard_data_retention_days, leaderboard_data_retention_reminder_days, tab_order. - **Premium (RevenueCat)** – Remove ads, lifetime access; paywall, premium status badge. (RevenueCatManager.kt, drawer, RevenueCatPaywall.kt, PremiumPurchaseDialog.kt)
- **Analytics** – Firebase Analytics; respects battery saver, DND, airplane, doze. (analytics_utils.kt)

## 4. Settings & Options

- **Theme** – Light / Dark (ThemeManager, QuickThemeSwitcher in ThemeSelector.kt); default dark.
- **Real-time monitor** – Toggle in drawer (start/stop SystemMonitorService).
- **App permissions** – Location, Phone Info, Network Usage Stats, Notification; toggles and “Grant Permissions” in drawer.
- **Notifications** – On/off (RetentionNotificationManager); toggle in drawer.
- **Widget** – Add to Home Screen; Add to Lock Screen (Android 14+); instructions dialog.

- **Open device settings** – Intent to system settings.
- **Open developer options** – Intent to developer options.

## 5. Technical Differentiators

- **Works offline** – Device info, health score, power tracking, privacy scans work without internet (README, FAQ).
- **No account required** – Use app without account; optional Gmail for leaderboard.
- **No root** – Uses standard Android APIs (BatteryManager, ActivityManager, etc.).
- **Privacy-first** – Local-first data; analytics off in battery saver, DND, airplane, doze; anonymous auth option.
- **AI export** – Share scan to ChatGPT, Gemini, Claude, etc., for plain-English explanations.
- **CSV export** – Power experiments (camera, display, CPU, network, app power) for research/sharing.
- **Real power measurement** – BatteryManager P = V × I; no fake estimates; 0 when unavailable.
- **Lock screen widget** – Home and lock screen (Android 13+) with live metrics.
- **Multi-language** – 19 locales (strings.xml).
- **RTL support** – android:supportsRtl="true".
- **Material Design 3** – Modern UI; light/dark theme.
- **In-app purchase** – Premium remove ads (RevenueCat); no ads for premium.
- **Deep links** – Referral (debugger://referral); Play Store link.
- **Widget deep navigation** – Tap widget opens Health (or other tab).
- **Verified reports** – Signed, shareable device report with verification code.
- **Background monitoring** – Foreground service for continuous monitoring (user-toggleable).
