🎤 Mic test, camera test, screen test
• Mic test / microphone test — mengukur noise floor ruangan dan level suara Anda, lalu memutar rekamannya agar Anda tahu bagaimana lawan bicara mendengar Anda. Rekaman tidak keluar dari ponsel
• Camera test — kamera tidak berfungsi? Kamera depan dan belakang, focus, warna melenceng
• Screen test — dead pixel test dan stuck pixel test dengan 9 warna layar penuh serta grid untuk goresan. Ponsel tidak bisa mendeteksi dead pixel-nya sendiri, jadi Anda yang melihat dan DeviceGPT mencatat jawaban Anda — bukan skor tebakan
• Phone hardware test: touch screen test, speaker test, GPS test, accelerometer
• FPS monitoring dan deteksi frame drop (Choreographer API)

🩺 App Doctor — "WiFi tersambung tapi tidak ada internet"
Wi-Fi tersambung tapi tidak ada yang terbuka? App Doctor mencari sebabnya:
• Ketik website apa pun, DeviceGPT mengujinya 4 kali — situs yang kadang gagal tidak bisa bersembunyi di balik satu percobaan yang kebetulan berhasil
• Menguji lewat koneksi biasa dan browser dalam aplikasi, jadi terlihat kapan masalahnya di Android System WebView sementara Chrome baik-baik saja
• Menampilkan server DNS, apakah Private DNS atau VPN aktif, dan apakah jaringan menahan Anda di halaman masuk (captive portal)
• Melaporkan jumlah percobaan berhasil dan rata-rata latency, bukan sekadar centang hijau

🔋 AI Battery Health — yang tidak ditampilkan Android
• Kondisi baterai, suhu, tanda penurunan kualitas
• Konsumsi daya saat ini dalam watt (fisika sungguhan: P = V × I)
• Rincian per komponen: display, cellular, RAM, Wi-Fi
• App screen time — Android tidak melaporkan pemakaian baterai per aplikasi, jadi ini peringkat waktu layar, bukan baterai
• Perilaku pengisian, cycle tracking, perbandingan isi cepat dan lambat
• WiFi speed test dan network speed test: download, upload, ping, jitter

🛡️ Zero Trust Dashboard — audit keamanan ponsel
Audit tiga bagian dengan skor 0–100:
• App Privacy Risk (35%): keylogger, perekam layar, aplikasi tersembunyi, pemindaian malware, penyalahgunaan mic/camera, ad tracker
• Network Trust (35%): manipulasi DNS, SSL hijack (MITM), transparent proxy, deep packet inspection, pelacakan ISP
• Device Integrity (30%): root, bootloader, sideloading, developer mode, izin overlay, notification listener
