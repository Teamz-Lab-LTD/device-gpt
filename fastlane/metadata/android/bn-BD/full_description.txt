🎤 Mic test, camera test, screen test
• Mic test / microphone test — ঘরের noise floor আর আপনার গলার level মাপে, তারপর record টা সাথে সাথে বাজিয়ে শোনায়, যাতে বোঝেন ওপাশের মানুষ আপনাকে কেমন শোনে। Record ফোনের বাইরে যায় না
• Camera test — camera কাজ করছে না? সামনের ও পিছনের camera, focus, রঙের গোলমাল
• Screen test — dead pixel test আর stuck pixel test, ৯টা full-screen রঙ আর আঁচড় দেখার grid। ফোন নিজের dead pixel নিজে ধরতে পারে না, তাই আপনি দেখেন আর DeviceGPT আপনার উত্তর লিখে রাখে — অনুমান করে score দেয় না
• Phone hardware test: touch screen test, সাথে GPS status আর পুরা sensor list (accelerometer সহ)
• FPS monitoring আর frame drop detection (Choreographer API)
