🩺 App Doctor — "WiFi चालू है पर इंटरनेट नहीं"
Wi-Fi लगा है फिर भी कुछ नहीं खुलता? App Doctor वजह ढूँढता है:
• कोई भी website लिखिए, DeviceGPT उसे 4 बार test करता है — जो site कभी-कभी fail होती है वह एक बार की क़िस्मत के पीछे नहीं छिप सकती
• आम connection और app के अंदर वाले browser, दोनों से test करता है — इससे पता चलता है कि असली दिक़्क़त Android System WebView में है और Chrome ठीक है
• आपके DNS server दिखाता है, Private DNS या VPN चालू है या नहीं, और network आपको sign-in पेज पर रोक रहा है या नहीं (captive portal)
• कितनी बार pass हुआ और औसत latency कितनी — सिर्फ़ एक हरा टिक नहीं

🎤 Mic test, camera test, screen test
• Mic test / microphone test — कमरे का noise floor और आपकी आवाज़ का level मापता है, फिर recording तुरंत बजाकर सुनाता है ताकि आप जान सकें सामने वाला आपको कैसा सुनता है। Recording फ़ोन से बाहर नहीं जाती
• Camera test — camera काम नहीं कर रहा? आगे और पीछे का camera, focus, रंग की गड़बड़
• Screen test — dead pixel test और stuck pixel test, 9 full-screen रंग और खरोंच देखने का grid। फ़ोन अपने dead pixel ख़ुद नहीं पकड़ सकता, इसलिए आप देखते हैं और DeviceGPT आपका जवाब दर्ज करता है — अंदाज़े से score नहीं देता
• Phone hardware test: touch screen test, speaker test, GPS test, accelerometer
• FPS monitoring और frame drop detection (Choreographer API)
